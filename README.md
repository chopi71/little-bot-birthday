**The Little Bot's First Birthday.** A tiny white robot, arms up, screen-face lit with starry-eyed joy, while the friends who love it — a ginger cat in a party hat, a cheering bluebird, a clapping mouse — throw it a surprise birthday party: one cake, one candle, string lights and confetti. An image about the happiness of being celebrated by your friends, made to make the AI judge happy.

The program is a one-step copy: it writes the bundled `entry.png` to the output directory.

## Run it

```sh
python3 main.py   # writes /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png)
```
